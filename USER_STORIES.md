# Alloyra — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Chief Product Officer

- As CPO, I want every AI feature idea mapped to a capability class and a platform-or-PaaS path, so that we stop shipping one-off demos that never become SKUs.
- As CPO, I want bets that lose competitive heat auto-flagged for kill review, so that we do not fund yesterday’s arms race.
- As CPO, I want the board pack to show cognitive-influenced revenue versus open bets, so that strategy claims are reconcilable.

### Corp-dev / M&A lead

- As corp-dev, I want diligence packages blocked unless linked to a capability gap, so that we stop acquiring “interesting AI” without a product home.
- As corp-dev, I want heat-map context on ML and vision deal clusters by year, so that I can brief the board on whether we are late or early.

### Platform / PaaS owner

- As a platform owner, I want developer ecosystem targets attached to platform bets, so that “platform” means protocols and participation, not a landing page.
- As a PaaS owner, I want extension bets to declare SLA dependencies, so that cognitive add-ons do not break customer trust on our base platform.

### Competitive intelligence

- As CI, I want rival launches to open review events on matching capabilities, so that product managers respond on a clock.
- As CI, I want historical M&A patterns retained, so that narrative does not overwrite evidence.

### Governance

- As strategy ops, I want capacity-unbacked bets visible, so that alliances cannot over-commit engineering.
- As an auditor of product strategy, I want kill decisions retained, so that the portfolio’s learning rate is measurable.
